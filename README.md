# Game Interaktif 2D dengan HTML5 Canvas
Game Interaktif 2D dengan HTML5 Canvas  game sederhana berbasis grid atau physics (seperti Flappy Bird clone atau Snake) menggunakan HTML5 <canvas>.  Konsep Utama: Game loop (requestAnimationFrame), deteksi tabrakan (collision detection), OOP (class JavaScript), manajemen aset gambar/audio.
